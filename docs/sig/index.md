# Assessment questionnaires

An independent code assessment starts with two questionnaires that describe the system at a high level. This section publishes our answers, so assessors, customers and contributors read the same description.

- [Maintainability questionnaire](./maintainability.md): technologies, the system boundary, the components and how they connect, the code that is out of scope, and how we test.
- [Security questionnaire](./security.md): the data flow and trust boundaries, inbound and outbound connections, data stores, and the controls for authentication, authorization, cryptography, input handling, configuration, logging and dependencies.

Each answer quotes the question, names the files it rests on and links the page on this site that covers the subject in more depth. The answers describe the code as of 9 November 2026. [ARCHITECTURE.md](https://github.com/ConductionNL/openregister/blob/main/ARCHITECTURE.md) in the repository gives the full component description.
