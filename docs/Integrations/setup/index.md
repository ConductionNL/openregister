# Setup guides

How to set up and use integrations, organised by what you are trying to do. Each guide maps to one or more [maturity tiers](../tiers.md).

| Guide | Tier | For |
|---|---|---|
| **[Using an integration](./using.md)** | 0–2 | End users linking and creating things in the UI |
| **[External integrations](./external.md)** | — | Connecting xWiki / OpenProject via OpenConnector |
| **[AI-agent / MCP setup](./mcp.md)** | 4 | Building an AI agent that reaches every leaf through one MCP tool |
| **[Admin notes](./admin.md)** | — | Admin-gated and read-only leaf behaviour |

:::tip The headline guide
**[AI-agent / MCP setup](./mcp.md)** is the Tier-4 capstone: it shows how a single Open Register MCP tool makes 24 integrations — including apps that ship no MCP of their own — addressable by an agent.
:::
