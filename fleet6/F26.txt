Duplicated blocks become ONE shared helper: a private method when the copies sit in one class, a small collaborator or a trait-free static helper in the same directory when they sit in several of your files; every copy then calls it. The same applies in JavaScript and Vue: helpers in the same module or a small module beside it (src/.../<name>.js), Vue computed properties and methods split into named helpers, duplicated template blocks into one child component only when the copies are identical in behaviour. BEHAVIOUR STAYS IDENTICAL: same return values, same exceptions and messages, same log calls, same order of side effects, same queries, same short-circuit order of conditions, same rendered markup and emitted events.
