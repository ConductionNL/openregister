# U06: references kept (SchemasController, the translation controller bags, `lib/Service/File`, `lib/Service/GraphQL`)

Wave 4 package U06 started from 8 references against the order in six Core files (main `3ec81519`).
Re-measured on main `c4e3349c`, all 8 were still there.

- **Removed by this package (#10953): 2.** `SchemasController -> AuthorizationAuditService` and
  `SchemasController -> ApprovalPositionFormGuard`, through Core ports.
- **Removed by open PRs of other packages: 3.** These are not duplicated here, so the two PRs do not
  conflict. They are listed below so that the ratchet's exceptions do not take them up if those PRs merge.
- **Kept: 3.** One for `FolderAccessDenial`, two for `ListAggregations`.
