- [x] 2.2 Guard `DbalObjectSourceProvider::connect()` per source, and make `find()` throw the 503 while the breaker is open instead of returning null. Verify: `tests/Unit/Service/ObjectSource/DbalObjectSourceBreakerTest.php` asserts the 503 on both `find()` and `findAll()` with no connect attempt.
  > 2026-11-14: `connect()` asks the `source:{id}` breaker before opening a connection and counts a connection error; each find, list and count query counts its outcome (a query error is a failure, a read a success). - [x] 2.3 Guard the LLM chat and embedding calls under key `llm`. Verify: `tests/Unit/Service/Chat/ResponseGenerationBreakerTest.php` asserts an open breaker refuses before LLPhant is constructed.

- [x] 2.4 Guard webhook delivery per host: an open breaker schedules the delivery on `WebhookRetryJob` for after the cool-down without counting an attempt, and the interception webhook continues at once (design D-6). Verify: `tests/Unit/Service/WebhookServiceBreakerTest.php`.
  > 2026-11-14: `WebhookService::deliverWebhook()` asks the `webhook:{host}` breaker before sending. A connection error, a 5xx and a 429 count as the receiver's failure; any other answer, a 4xx included, as a success. While open nothing is sent: the log row is saved unsuccessful with `next_retry_at` at the end of the cool-down and the attempt before this one, so `WebhookRetryJob` (which sends attempt + 1) sends the same attempt again; the webhook's statistics are not touched. An interception delivery takes the same path and so returns at once instead of waiting for its 2 second timeout. Test: `tests/Unit/Service/WebhookServiceBreakerTest.php`.
