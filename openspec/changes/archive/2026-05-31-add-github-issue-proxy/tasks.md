## 3. Caching + rate limiting

- [x] 3.1 Implement in-memory TTL cache (15 min) keyed by `(repo, state, sort, per_page, labels-sorted)` for GET only; set `X-OpenRegister-GitHub-Cache: HIT|MISS` response header.
- [x] 3.2 Abstract the rate-limiter behind an interface; primary impl uses APCu, fallback impl uses Nextcloud's `ICacheFactory::createDistributed()` / `createLocking()`; when neither is available, fail closed with HTTP 503 `rate_limiter_unavailable`. POST submission limiter: key `openregister.feature_submission:<user_id>`, 60s TTL, HTTP 429 `{error: "rate_limited", retry_after}` on exceed. GET per-user cache-miss limiter: max 10 distinct cache keys per user per 5 min (cache hits don't count); on exceed → HTTP 429 `{error: "user_rate_limited", retry_after}`.
- [x] 3.3 Map GitHub rate-limit (403 with `X-RateLimit-Remaining: 0`, or 429) to HTTP 429 `{error: "github_rate_limited", reset_at: "<ISO-8601>"}` derived from `X-RateLimit-Reset`.
