# Screens

The flow screens are one set (decision 379, 5 Nov 2026): the canonical boards live under OpenRegister, and an app's flow board is a variant that imports the shared parts with the app's own example flow, step types and wording.

- openregister/OrFlow: the step palette lists the actions an app contributes, grouped per app https://identity.conduction.nl/screens/board?id=openregister/OrFlow
- openregister/OrFlowLijst: the same actions as ordered steps in list mode https://identity.conduction.nl/screens/board?id=openregister/OrFlowLijst
