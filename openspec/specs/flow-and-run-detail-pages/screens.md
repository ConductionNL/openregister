# Screens

The flow screens are one set (decision 379, 5 Nov 2026): the canonical boards live under OpenRegister, and an app's flow board is a variant that imports the shared parts with the app's own example flow, step types and wording.

- openregister/OrFlows: the flows overview https://identity.conduction.nl/screens/board?id=openregister/OrFlows
- openregister/OrFlow: the flow editor in canvas mode https://identity.conduction.nl/screens/board?id=openregister/OrFlow
- openregister/OrFlowLijst: the same flow in list mode, the Canvas / Lijst switch in the header https://identity.conduction.nl/screens/board?id=openregister/OrFlowLijst
- openregister/OrFlowRun: a run on the canvas https://identity.conduction.nl/screens/board?id=openregister/OrFlowRun
- openregister/OrFlowTestrun: the test run https://identity.conduction.nl/screens/board?id=openregister/OrFlowTestrun
- openregister/OrFlowOverzicht: one flow: lifecycle and run history https://identity.conduction.nl/screens/board?id=openregister/OrFlowOverzicht
- openregister/OrFlowDashboardWidget: the runs widget https://identity.conduction.nl/screens/board?id=openregister/OrFlowDashboardWidget
- openregister/OrFlowStaten: lifecycle and the empty, error, no permission and loading states https://identity.conduction.nl/screens/board?id=openregister/OrFlowStaten

Adopted by apps:

- planninq/PlFlows: the flows that act on tasks, listed and edited (rows int-flows, int-automation-edit) (planninq adopts this) https://identity.conduction.nl/screens/board?id=planninq/PlFlows
