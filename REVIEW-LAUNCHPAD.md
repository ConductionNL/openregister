18. [ ] (Ruben, 27 Nov ~11:45 CET) Versions are not created: Ruben changed and saved 'My Dashboard' and the Versions tab says 'No versions saved yet' (API: versions []). Cause: DashboardVersionService::captureSnapshot (automatic, debounced 60 s) is only called from the dashboard settings PUT (DashboardApiController ~l.1043); adding, moving, resizing or configuring widgets goes through other endpoints and never snapshots, and edit mode autosaves so there is no save moment. Fix: every Save of edit mode (item 10) creates one version of the whole dashboard (layout + widget config + look), and so does every save of Dashboard settings; the very first version also captures the state before the change, so there is always something to restore. Restore brings back layout and widgets. e2e: change a widget, Save, a version appears and restoring it brings the old widget back.

It uses nextcloud-vue's admin settings template (CnVersionInfoCard first, then a CnSettingsSection per feature, ADR-004 'Settings'), NOT launchpad's app shell/manifest page, so buildiq cannot reach or customise admin pages. Users who manage announcements but are not admins get it as a delegated admin setting (#[AuthorizedAdminSetting]).
