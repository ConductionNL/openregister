# REVIEW-THEMATIQ.md: Ruben's review findings on thematiq (live on a reference instance, 27 Nov 2026)

Findings from Ruben's own review. Each one blocks thematiq DONE. The DONE lane and the thematiq builder work them first, one PR each, live-verified, then tick them here with the PR number. Boards are canon; where a finding needs new screens, a Fable design agent draws them in ConductionNL/design-system first (the coordinator starts it).

1. [ ] Apps menu walkthrough. thematiq has no walkthrough at all. Add a feature walkthrough for the apps menu with nextcloud-vue's walkthrough (CnWalkthrough, the same mechanism and look the other apps use), covering: how to open the menu (button and keyboard), the app list, 'More' (expand/collapse) and how to move apps between the main list and More, reordering (drag, Alt + arrow keys), pinning an app to the top bar and unpinning (drag, Alt+P), the Create section, and Menu settings. It starts automatically the first time a user opens the apps menu, can be replayed (from Menu settings and the user's help entry), and is version-gated so a new menu feature gets its own step when it ships. One step per feature, short Dutch and English copy in the Conduction voice (no em-dashes, sentence case). Spec it as an openspec change in thematiq (apps-menu-walkthrough) with an e2e test that walks every step and checks the pin/move/reorder actions it explains actually work; boards for the steps come from the Fable design agent.
2. [ ] (Ruben, 27 Nov ~13:40 CET) Welcome screen and first-time setup wizard, as the other apps have (ADR-042, nextcloud-vue's setup wizard with the standard /api/setup/status|action|config contract). thematiq has none today. thematiq lives in Nextcloud's admin settings (Theming), so the wizard opens there the first time an administrator opens thematiq's settings after install (and can be run again from the version card, 'Set up again'). Steps: welcome (what thematiq does); choose the house style (token set, with the licence confirmation for restricted sets); apply it to Nextcloud's own theming (logo, colours, favicon: the --sync-core behaviour); login page style; the apps menu (on/off and its defaults); finish, which offers the apps menu walkthrough (item 1). Completion is derived from the saved configuration, so an instance already configured counts as set up. Spec it as an openspec change (first-time-setup) with e2e; boards from the Fable design agent.
