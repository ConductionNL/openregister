## Callers to switch

**1. The object history endpoint moves to Compliance's AuditTrailController** (compliance.md B5f): `ObjectsController::logs` (with `logsForReader`, `logsPage`, `historyObject`) moves to `AuditTrailController::objectLogs`, which already serves the audit-trails route with the same reader redaction. `appinfo/routes.php` keeps `/api/objects/{register}/{schema}/{id}/logs` and `GET`; the route name becomes `auditTrail#objectLogs`. The purpose refusal catch in `ObjectsController` catches `ReadPurposeRefusalInterface`.

**2. The bulk download endpoint moves to a Files controller** (files.md B4): `downloadFiles` and its private `auditBulkDownload` move from `ObjectsController` to `ObjectFilesArchiveController` (autowired). `appinfo/routes.php` keeps `/api/objects/{register}/{schema}/{id}/files/download` and `GET`; route name `objectFilesArchive#downloadFiles`. Object lookup and access check run in the same order.

**3. Geo endpoints move to a Search GeoController** (search.md S4c): `geoSearch`, `geoJson`, `wfs` move from `ObjectsController` to `GeoController`; `appinfo/routes.php` keeps each URL and verb, route names `geo#...`; `geocode` and `geoFeatures` stay. The index listing narrows through `SpatialFilterInterface`.
