## Notes

- Each port is implemented by ONE Core class: the existing service, or a thin facade in the capability's Nextcloud directory that delegates without changing order, checks or failure behaviour. A facade exposes only the methods listed; never widen it per request (core.md section 4).
- Constants on ports are literals equal to today's value, asserted equal by a unit test, never `= ConcreteClass::X`.
- NOT in this package, by decision of this wave: `AuditRecorderInterface` is created by X20 (Comp-audit) (Compliance owns its implementation and adds two typed writes); `AggregationInterface` is dropped in favour of Search's `AggregationResultsInterface` (package X84 (S-aggregation)); `OrganisationInterface` is NOT created: the Kernel `Kernel/Contracts/OrganisationInterface` exists, `Db/Organisation` implements it if it does not yet, and `TenancyInterface` returns it.
- The four `...DeclarationException` classes keep their names and extend `SchemaDeclarationException`; check whether `Kernel/Contracts/Core/DeclarationRefusalInterface` (exists) already covers what the checks catch before adding the base.
- Reuse before you add: see WAVE5.md "Ports that already exist".
