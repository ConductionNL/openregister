COMMON RULES

METRICS: unit size counts a unit's lines of code (NLOC) once it is over 15; unit complexity is McCabe (lizard's count: 1 + each if, elseif, case, loop, catch, ternary, && and ||); unit interfacing counts parameters; each is the share of a language's unit lines in units over three bounds (size 15 / 30 / 60, complexity 5 / 10 / 25, parameters 2 / 4 / 6), each band rated separately and the lowest band wins, so a method split into helpers that are still over 15 lines or over complexity 5 barely moves the rating. Duplication counts every redundant line in a window of 6 code lines that occurs elsewhere in the same language (equal modulo whitespace; in a Vue file template, script and style are separate pieces); a redundant line weighs about eight times an over-15 unit line. Module coupling is the share of a language's module lines that sit in modules (PHP classes) with fan-in over 10, 20 and 50, where fan-in counts the other PHP files that reference the class (a `use` import, a fully-qualified name, or a bare name in the same namespace). Whatever your slot's property, every unit you add or change ends at 15 lines of code or fewer, complexity 5 or below and at most 2 parameters, and you add no duplicated block and no new reference to a class with fan-in over 10 that the code did not already have, so your work never makes another property worse.
