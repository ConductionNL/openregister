Nightly check lane <LANE> (your app group is in your launch message). GitHub Actions starts no jobs in the ConductionNL org until about 1 December, so this run replaces the nightly CI: it measures, it does not fix.

SETUP: `git config --global user.name "Juan Claude" && git config --global user.email "juan.claude@conduction.nl"`. Every app in your group is a source repository of this session under /home/user/<app>.

PER APP, in order:
1. In /home/user/<app>: `git fetch -q origin <base>` (base is `main` for openregister, `development` for every other app) and `git checkout -q -f FETCH_HEAD`. Note the short sha.
2. `env -u GH_TOKEN -u GITHUB_TOKEN COMPOSER_ALLOW_SUPERUSER=1 composer install --no-interaction --prefer-dist` then `COMPOSER_PROCESS_TIMEOUT=0 composer check:strict > ~/night-<app>-php.log 2>&1; echo $?`. A green suite can exit 1 without a coverage driver: also read the PHPUnit `Tests:`/`Failures:`/`Errors:` line and the summary line of each tool (phpcs, phpmd, psalm, phpstan) from the log.
3. If the app has package.json with a `test:unit` or `test` script: `npm ci --no-audit --no-fund` then `npm run lint > ~/night-<app>-js.log 2>&1; echo $?` and `npm run test:unit` (or `npm test`) appended to the same log.
4. Record one line per app on the state branch. Take the state branch as a worktree of the session's own openregister repository, not a fresh clone: `cd /home/user/openregister && git fetch -q origin +refs/heads/sig-pipeline/state:refs/remotes/origin/sig-pipeline/state && git worktree add -q --detach ~/state origin/sig-pipeline/state` (once), then `export ST=~/state ST_ME_FILE=~/.night-id && source ~/state/bin/state.sh && st_append nightly/$(date -u +%F).tsv "<app>\t<sha>\tphp=<GREEN|RED>\t<phpunit Tests/Failures/Errors>\t<tools that failed, comma-separated, or none>\tjs=<GREEN|RED|n/a>\t<one-line note>"`.
   RED means a failure; name the failing tool or test class in the note (at most 120 characters). Never paste log content beyond that.
5. Remove vendor/ and node_modules/ of that app before the next one, to keep disk free.

Never commit to or push any app branch, never open PRs or issues, never comment. Kill processes only by the PID you started. Anything over 3 minutes runs with nohup and you wait in foreground `timeout 170` windows; never end your turn while something runs. Decide every question yourself; never ask.
FINAL MESSAGE (at most 12 lines): one line per app as recorded.
